# Two Sum

## Approach

One-pass hash map: `value -> index` for numbers already seen. For each number, compute its complement (p2) (`target - nums[i]`) and check the map. Found → return the answer. Not found → insert current number, and move on. Works in one pass since every earlier index is already recorded by the time we reach `i`.

## Code

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int>m; // num, index
        int nums_arr_size = nums.size();

        for(int i = 0; i < nums_arr_size; i++){
            int p1 = nums[i];
            int p2 = target - p1;

            if(m.count(p2) > 0){
                return {m[p2], i};
            } else {
                m.insert({p1, i});
            }
        }

        return {};
    }
};
```

## Walkthrough

- `m` maps number → index it was found at.
- `p1` = current number, `p2` = its needed complement.
- `m.count(p2) > 0` is an existence check (keys are unique, so count is 0 or 1).
- Found → `{m[p2], i}`, earlier index first.
- Not found → insert `{p1, i}` for later lookups.
- `return {};` is just a fallback; never hit given the problem's guarantee.

## Complexity

- Time: `O(n)` — single pass, and hash map lookup/insert is average `O(1)`.
- Space: `O(n)` — worst case, we store almost the whole array in the map before finding a match.
